Point 02

Project Description

Cyber Secure

What is Cyber Secure?

Cyber Secure is a Flask-powered web application serving as a citizen awareness hub and incident management portal.

  • Scam Directory: Interactive catalogs explaining UPI collect frauds, AI Voice Phishing, and malicious APK installs.
  • Standard Operating Procedures (SOPs): Guided action steps to help victims mitigate losses immediately.
  • Incident Filing Panel: Form allowing secure details logging and file attachments for digital evidence.
  • Admin Control Console: System for authorized moderators to monitor, process, and resolve incidents.
Point 03

Why We Chose/Made This Project

Cyber Secure

Critical National Cybersecurity Need

Rapid deployment of digital services (UPI, QR Codes) has created a significant vector for social engineering scams.

  • Spike in Scams: High frequency of AI voice cloning, deepfake video distress scams, and courier phishing.
  • Vulnerable Demographics: Non-technical citizens and elderly populations are targeted with complex psychological traps.
  • Inefficient Reporting: Complex layouts on traditional portals often delay reports during critical periods.
  • Lack of Incident SOPs: Citizens often don't know what step to take immediately after being scammed.

Project Vision

By providing clean, simplistic interactive interfaces, we aim to decrease reporting friction, guide the user on immediate action, and help resolve cases faster via admin tools.

This project integrates real-world cyber defense modules with client-server interactions to simulate a functional public utility.

Point 07

Database Design

Cyber Secure

Relational Schema & Integrity

The database uses relational associations to connect registered users to their submitted complaints securely.

  • Relational DB Model: Implemented using SQLite3 for quick transactional safety (ACID).
  • Unique Index Constraints: Prevents duplicate registrations with unique keys on the `users` table email column.
  • Foreign Key Cascading: Associates `complaints.user_id` with `users.id` for clear user ownership of complaints.
  • Random ID Generation: Generates secure alphanumeric tracking identifiers (e.g. CC4829).

Point 14

Challenges Faced During Development

Cyber Secure
  • File Upload Security: Mitigated malicious upload threats by enforcing secure filename checking via Flask utilities.
  • Complex Responsive Flexboxes: Ensured the custom layout fits on narrow viewports without using bloated frameworks.
  • SQLite Thread Locking: Handled multi-threaded database transaction errors by keeping connections short and properly closing cursor connections.
  • State Management Persistence: Cleaned route sessions correctly to prevent normal users from reading admin panels.

Debugging Methods

Used standard SQLite CLI database queries to verify storage transactions, browser developer tools to fix styling issues, and Flask logging streams to diagnose routing errors.
